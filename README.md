# Jester D. Mosquera - Portfolio Website

Midterm project: personal website portfolio (BSIT, CVSU Bacoor Campus).

## Files
- `index.html` - portfolio (Home, About, Projects & Certificates, Contact)
- `crunchora/index.html` - CRUNCHORA project website (live demo)

## Deploy on GitHub Pages
1. Create a new repository (e.g. `jester-portfolio`) and upload everything in this folder, keeping the `crunchora` folder.
2. Go to Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
3. After a minute your site is live at `https://<username>.github.io/jester-portfolio/`
   and the demo at `https://<username>.github.io/jester-portfolio/crunchora/`.

Tip: name the repo `<username>.github.io` to get the shorter URL `https://<username>.github.io/`.
